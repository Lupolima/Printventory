Printventory Watcher

How it works

  1. This extension does not open or edit printventory.db. Chrome blocks that folder (“system files”).
  2. When you add a page or download a model, the extension writes a small inbox file to Downloads/PrintventoryInbox.
  3. The Printventory app watches that folder, imports the file into your library, and updates the database itself.

Usage

Use the toolbar popup on a model page to confirm title/designer. Downloads from supported sites are queued automatically. STL, OBJ, and 3MF are queued from any site.
